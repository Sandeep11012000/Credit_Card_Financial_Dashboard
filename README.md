# Credit_Card_Financial_Dashboard
A Power BI project for analyzing credit card transactions, customer behavior, revenue
performance, transaction volume, interest earned, and customer segmentation.

This dashboard transforms credit card data into two interactive reports:
1. Credit Card Transaction Report – focuses on revenue, transaction amount, interest earned,
transaction volume, card categories, expenditure types, customer jobs, education levels,
and usage channels.
2. Credit Card Customer Report – focuses on customer demographics, revenue trends,
income, marital status, dependents, education, states, customer jobs, and customer
satisfaction.
